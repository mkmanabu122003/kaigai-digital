# SEO改善 作業キュー

`/loop` で自動消化するタスクリスト。**1周につき未完了タスクを1つだけ**処理する。

- 完了したら `[x]` に変え、「完了日」と「結果」を追記する
- **すべて `[x]` になったらループを停止する**（新しいタスクを勝手に作らない）
- 判断に迷ったら実行せず、タスクに `⚠️ 要判断` と追記して次へ進む

---

## 実行ルール（厳守）

1. **開始時に必ず `git pull --rebase origin main`** — データはGitHub Actionsが毎日更新している。pullしないと古い前提で作業することになる
2. **1周1タスク。** 複数を同時に進めない
3. **検証を通らなければコミットしない：**
   ```bash
   npx tsx scripts/quality-check.ts      # Errors: 0 であること
   npx tsx scripts/check-internal-links.ts  # リンク切れ0・孤立0 であること
   npm run build                          # 成功すること
   ```
   1つでも失敗したら、変更を `git checkout -- <file>` で戻し、タスクに `⚠️ 失敗理由` を記録して次へ
4. **記事の削除・統合は禁止。** このキューでは加筆と内部リンク追加のみ行う
5. **編集した記事は `updatedAt` を実行日に更新する**
6. コミット後は `git push origin main` し、変更した記事URLを Indexing API へ送信：
   ```bash
   npx tsx scripts/request-indexing.ts --urls "https://kaigai-digital.com/..."
   ```
7. **事実の捏造をしない。** 「編集部が実測した」等、自社の一次データを装う表現は禁止。料金・仕様は「公式で確認」と促す書き方にする
