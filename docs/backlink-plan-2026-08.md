# 被リンク獲得プラン（DR0脱出）

作成日: 2026-08-06
現状: **Ahrefs Domain Rating = 0.0**

---

## 1. なぜこれが最優先なのか

2026-08-05時点の実測データが示していること。

| 指標 | 値 |
|---|---|
| Domain Rating | **0.0** |
| インデックス済み | 19 / 75本（25.3%） |
| 検出・インデックス未登録 | 45本 |
| 28日間の表示回数 | 263 |
| 28日間のオーガニックセッション | **21** |

7月末からインデックスは回復基調にある（11本 → 19本）。しかし**表示回数は4月ピークの41%に留まり、クリックは月5件**。

理由は単純で、**DR0のドメインは検索順位が上がらない**。統廃合で記事の質を上げ、インデックスされるところまでは到達できるが、そこから1ページ目に食い込むには外部からの評価が要る。

> 統廃合が「弾の命中率を上げる」施策なら、被リンクは「射程を伸ばす」施策にあたる。両方ないと届かない。

## 2. 実行プラン（優先度順）

### 優先度A：今週中に着手（無料・即効性あり）

| # | 施策 | 所要 | 備考 |
|---|---|---|---|
| A-1 | **X（旧Twitter）アカウント開設** | 30分 | プロフィールにサイトURL。渡航系の情報発信で認知獲得 |
| A-2 | **note アカウント開設＋記事投稿** | 2h/本 | 記事末尾から本サイトへ誘導。noteはドメインが強く、記事自体が検索に乗る |
| A-3 | **はてなブログ開設＋記事投稿** | 2h/本 | 同上。はてなブックマーク経由の拡散も狙える |
| A-4 | **人気ブログランキング登録** | 30分 | 海外生活カテゴリ。日本のブログ界隈では依然として有効 |
| A-5 | **ブログ村のカテゴリ最適化** | 30分 | ping送信は設定済み（`scripts/ping-blogmura.ts`）。カテゴリが適切か、記事一覧に反映されているかを確認 |

> **注意：** nofollowリンクでもGoogleは2019年以降「ヒント」として扱う。SNSやnoteのリンクは直接的なDR上昇には効きにくいが、**そこから自然リンクが生まれる導線**として機能する。

### 優先度B：今月中（無料・中期）

| # | 施策 | 備考 |
|---|---|---|
| B-1 | **Pinterest運用** | 旅行系と相性が良い。記事のアイキャッチを投稿しリンクを貼る |
| B-2 | **海外駐在系コミュニティへの参加** | Facebookグループ、mixiコミュニティ。宣伝ではなく質問への回答を通じて認知を得る |
| B-3 | **同ジャンル個人ブログへの寄稿・相互リンク打診** | 「海外赴任」「駐在妻」系ブログ。10件打診して1〜2件成立すれば上出来 |
| B-4 | **Yahoo!知恵袋での回答** | **規約に注意。** URLの直接投稿は制限される場合がある。回答の質で認知を得る用途に留める |

### 優先度C：予算があれば

| # | 施策 | 費用 | 判断 |
|---|---|---|---|
| C-1 | PR TIMES等のプレスリリース | 3万円〜 | 配信先メディアに転載されれば被リンクになるが、**個人サイトでは転載率が低い**。費用対効果は不確実 |
| C-2 | 有料ディレクトリ登録 | 数千円〜 | **推奨しない。** 低品質リンクはペナルティリスクがある |

### やってはいけないこと

- 被リンク購入（自作自演リンク）
- 相互リンク集への大量登録
- 中身のないサテライトサイトの量産

いずれもGoogleのリンクスパムポリシー違反であり、**DR0より悪い状態（手動対策）**を招く。

## 3. 「リンクされる理由」を作る

登録できる場所に登録するだけでは、DRは上がっても数ポイントで頭打ちになる。**自然リンクを得るには引用される理由が必要**だ。

現在の記事は「他サイトにもある情報の再構成」に留まっており、引用する動機が生まれにくい。

### 引用されやすいコンテンツの型

| 型 | 具体案 | 実現可能性 |
|---|---|---|
| **網羅的データベース** | 「海外eSIM 20社 料金比較データベース」 | ◎ 公開情報の集約で作れる |
| **一覧マップ** | 「国別 VPN規制マップ」（規制の強度を国ごとに整理） | ◎ 公開情報ベース |
| **全比較表** | 「主要クレカ20枚 海外旅行保険 補償額 全比較」 | ◎ 各社公式の公表値を集約 |
| **手順の完全版** | 「eSIM設定 全キャリア・全機種対応ガイド」 | ○ 工数は大きい |

いずれも**一次データ（自社実測）は不要**で、公開情報を網羅的に集約・整理することで「調べる手間を省く価値」を生む。これは引用の動機になる。

> 逆に、実測していないデータを実測したかのように書くのは**絶対に避ける**。信頼を失うだけでなく、アフィリエイトの規約違反にもなる。

## 4. 発リンク（外部への引用）も不足している

被リンクとは別に、**このサイトから外部へのリンクが66記事で6箇所しかない**という問題がある。

```
eposcard.co.jp / surfshark.com / nordvpn.com /
network.mobile.rakuten.co.jp / kabeneko.net / neverssl.com
```

記事中で「公式サイトで確認してほしい」と繰り返し書いているにもかかわらず、**実際にはリンクしていない**。Googleは権威ある情報源への発リンクをE-E-A-Tの評価材料のひとつとして扱う。

### 追加すべき発リンク先の例

| 記事テーマ | リンクすべき権威サイト |
|---|---|
| 海外旅行保険 | 厚生労働省（海外療養費制度）、日本損害保険協会 |
| 海外の医療費 | 外務省「海外安全ホームページ」 |
| 中国のネット規制 | 各サービスの公式ヘルプ |
| eSIM対応端末 | Apple / Google の公式サポートページ |
| クレカ付帯保険 | 各カード会社の公式約款ページ |

**これは私（Claude）が実行できる作業**なので、指示があれば主要記事から順に追加する。

## 6. 現実的な収益見通し

冷静な逆算をしておく。VPN案件の単価を4,000円と仮定する。

```
月1万円 = 2.5件のCV
  ÷ ASP成約率 1%     → 250回のASPクリック
  ÷ CTAクリック率 15% → 1,667セッション/月
```

現在のオーガニックは**月21セッション**。約80倍の開きがある。

これは記事を増やして埋まる差ではない。**DR0を脱し、既存の厚い記事が1ページ目に入ることでしか埋まらない**。逆に言えば、`/compare/best-vpn`（現在10.2位）が3位以内に入るだけで、この数字の相当部分が現実になる。

打ち手の順序としては：

1. 被リンクでドメインの土台を作る（本ドキュメント）
2. 統廃合で記事の密度を上げる（`docs/consolidation-plan-2026-08-06.md`、Phase 1は実行済み）
3. 上位候補ページを厚くする（実行済み：best-vpn / travel-insurance / taiwan-esim / paypay）

2と3は着手済みなので、**残るボトルネックは1つだけ**という状態にある。
